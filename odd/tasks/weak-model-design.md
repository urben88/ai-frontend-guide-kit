# weak-model-design

Objective: make the kit drive a weak model, step by step, to a practical, good-looking, well-structured page: the tool gives each instruction and checks each result, instead of trusting the model to read, choose and judge.
Branch: `feat/weak-model-design`, stacked on `feat/free-sources` (pushed 2026-11-13, no PR yet). Delivery: ask-on-risk. Test runner: `node --test` (`npm run verify`).

## Specs

- **S1 — Goal.** "el objetivo es que convierta un modelo tonto en un agente perfecto para poder generar páginas web y diseñar de manera bonita, visual, estructurada." / "para hacer que agentes, modelos menos inteligentes puedan funcionar muy bien y diseñar de manera muy correcta."
- **S2 — Guided steps and standards.** "tiene que seguir ciertos pasos y ciertos estándares que deberá de seguir. Pero toda esta información se le tiene que ir guiando gracias a esta herramienta."
- **S3 — Design from the business logic.** "elegir los diseños y rediseñar una página web, el UX, basándose en su lógica de negocio."
- **S4 — Output quality.** "crear una página web práctica, bonita y bien estructurada, maquetada perfectamente."
- **S5 — Works for other people.** "mejorar el sistema que se está usando, para que funcione bien con otra gente".
- **S6 — SVG.** "Deben de haber también herramientas para poder generar tanto dibujos SVG prácticos, bonitos y armónicos".
- **S7 — 3D.** "poder tener instrucciones para generar cosas en 3D, pero que genere las instrucciones". Assumption (not confirmed): the kit guides the agent to write a scene specification first (purpose, camera, light, materials from the tokens, performance budget, fallback) and then code or a prompt for an external 3D tool from it.
- **S8 — Shape.** "al final van a ser una serie de skills, herramientas y funcionalidades para poder generar, tener esa buena salida de diseño."
- **S9 — Technique repertoire.** "quiero que chequees también todo este listado extenso de técnicas a usar para cuando se pide un diseño diferente." / "que tenga el conocimiento. Al final le quiero ofrecer conocimiento, saber darle un repertorio de técnicas y de catálogo que pude hacer a la gente para poder empezar a desarrollar diseño de manera correcta." The list, verbatim: `odd/tasks/weak-model-design-techniques.md` (14 sections).
- **S10 — Routing, cheap in tokens, through skills.** "tiene que saber redirigir bien a la gente a cada apartado y ofrecerle todas las técnicas necesarias y de manera optimizada para no consumir muchos tokens. Pero tener herramientas como skills para poder tomar todo este diseño."
- **S11 — No explaining to each new agent.** "No tener que, siempre al empezar a un nuevo agente, tener que explicarse que tiene nuestra herramienta instalada y saber buscar entre estas técnicas que existen. Y las tener que ordenar y todo esto. Integrarlo."
- **S12 — Applied psychology.** "Quiero que guardes para hacer también el análisis de estas técnicas a la hora de implementar, cuando quieres implementar algo de diseño, pensar estas cosas también." / "tener en cuenta estas cosas que hay que hacer e integrar." The list, verbatim: `odd/tasks/weak-model-design-psychology.md` (attention, cognitive load, motivation, emotion, page distribution, forms, navigation, trust, motion, personalization, scroll, anti-manipulation, a per-screen checklist, ten modules).
