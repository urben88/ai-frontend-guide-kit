# free-sources

Objective: index large free/open-source component sources (ReUI first), drop sources whose free catalog is small behind a paywall, and make search and agents strictly prefer catalog components from big free sources over building new ones.
Branch: `feat/free-sources` (from main 7713a6a). Delivery: ask-on-risk. Test runner: `node --test`.

## Specs

- **S1 — New sources.** Add these sources to the catalog: "https://reui.io/components https://github.com/shadcnspace/shadcnspace https://blocks.so https://uiable.com/components https://www.indoui.com/ https://github.com/tabler/tabler https://flowbite-react.com/". Index only the free/open-source part of each (shadcnspace and ReUI have paid Pro tiers that stay out).
- **S2 — ReUI in depth.** "Quiero reindexar esa página bastante bien y que sea una de las primeras opciones a elegir." Registry: `https://reui.io/r/registry.json` (2,028 items on 2026-11-06: 1,942 `registry:block`, 82 `registry:ui`, 4 `registry:hook`), MIT.
- **S3 — Drop mostly-paid sources.** "filtrar un poquito entre enlaces los cuales tengan cosas de pago ... parte de su catálogo es de pago. Entonces de nada me sirven, hay poca cantidad, entonces los quiero quitar en ese caso." Decided (L6-L7): remove hover; replace flowbite (HTML) with flowbite-react; do not add Shadcn Blocks (2,467+ Pro blocks vs ~169 free). Keep aceternity, magicui, preline, motionprimitives, cultui, 21stdev (relevant, free part large enough). User criterion: "Quizás solo las que no sean muy relevantes.Y no ofrezcan muchas opciones porque creo que si la mayoría son de pago pon... de poco me sirve."
- **S4 — Source order.** "Que ordenes a la hora de elegir entre páginas." "quiero coger que estas páginas que tengan muchos componentes gratis sea lo primero que haga y que sea muy estricto con eso." Ranking prefers sources with many free components. Role order (L5): "ReUI como galería principal: tiene muchos ejemplos de componentes en contextos reales, especialmente tablas y dashboards." / "shadcn/ui oficial como base del sistema de diseño." / "Shadcn Space o Shadcn Blocks cuando necesites un bloque ya montado: por ejemplo, una tabla con filtros, un formulario de alta, un modal de confirmación o un dashboard." Assumption: Shadcn Blocks (shadcnblocks.com) is mostly paid; only its free part could be indexed, pending verification.
- **S5 — Better search and reuse.** "mejora también la indexación para que la gente pueda buscar de manera correcta. Porque muchas veces lo que hace es que coge lo básico, no le da prioridad a coger estos componentes. No veo que esté funcionando, creo que lo genera nuevo." Agents must find and pick catalog components instead of generating new ones; reproduce the failure first. L7: "mejora la manera en la que esta herramienta inyecta o le dice a la gente de manera más agresiva que busquen estos componentes y primero tire de donde buscar estos componentes y usarlos" — the injected agent block, guides and skill must make catalog search the mandatory first step, in source order (S4).
