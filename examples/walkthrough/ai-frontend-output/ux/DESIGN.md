# Design tokens — Tidewatch

Source of truth: `site/tokens.css`. Outdoor-first: high contrast, large type, generous targets.

| Token | Value | Use |
|---|---|---|
| `--color-bg` | `#f7fafc` | page background |
| `--color-surface` | `#ffffff` | cards |
| `--color-text` | `#0b1f2a` | body (contrast 16:1 on bg) |
| `--color-muted` | `#3d5565` | secondary text (7.5:1) |
| `--color-accent` | `#0b5d7a` | links, primary button (7.3:1 with white text) |
| `--color-focus` | `#c2410c` | focus ring (4.9:1 on bg, 5.2:1 on surface; WCAG asks 3:1) |
| `--radius` | `10px` | single radius, no mixed radii |
| `--space-*` | 4 / 8 / 16 / 24 / 40 px | spacing scale |
| `--text-*` | 1rem / 1.25rem / 2.25rem | exactly three sizes |
