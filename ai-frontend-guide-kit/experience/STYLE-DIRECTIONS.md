# Style Directions

A style is a visual language, not a palette. Choose with `--task direction` (Laya) or with the "fits when / avoid when" columns, and always state why. The style is not decoration: it must express the philosophy and the subject matter. Full dictionaries: Superdesign, StyleKit, Design Binders, IndexStyle, Design Lexicon.

## Style catalogue (with honest limits)

| Style | Feels like | Fits when | Avoid / risk |
|---|---|---|---|
| Minimalist functional | Calm, precise | Tools, docs, high-frequency use | Can be anonymous; relies on spacing/type craft |
| Editorial | Magazine, authority | Content, stories, brands with voice | Weak for dense data; needs real typography |
| Swiss / typographic grid | Rational, rigorous | Systems, architecture, portfolios | Cold if over-applied; grid discipline required |
| Brutalism (raw) | Raw, structural | Statements, art, dev culture | Usability friction; polarizing |
| Neubrutalism | Bold, loud, playful | Startups, creative tools | Contrast/visual stress; dated if overused |
| Bento grid | Ordered, modular | Feature overviews, dashboards summaries | Becomes decoration without hierarchy; Apple-effect default |
| Glassmorphism | Depth, tech elegance | Dark hero sections, overlays | Readability/contrast traps; GPU cost |
| Neumorphism | Soft, molded | Small widgets, playful demos | Contrast trap; poor for text-heavy UI |
| Claymorphism | Friendly, inflated | Kids, wellness, casual products | Childish for serious domains |
| Maximalism | Expressive, rich | Fashion, culture, launches | Performance and focus costs |
| Retro / Y2K | Nostalgic, playful | Campaigns, games, culture | Legibility; ironic distance |
| Terminal / developer | Technical, precise | Dev tools, dashboards, CLIs | Alienates non-technical users |
| Industrial / technical | Rugged, reliable | IoT, manufacturing, field tools | Dense; needs strong state design |
| Data-dense | Informative, serious | Analytics, operations | Overload without hierarchy; accessibility |
| Luxury / premium | Restrained, exclusive | High-price services, fashion | Empty-feeling without craft; slow conversions |
| Organic / natural | Warm, human | Health, food, sustainability | Vagueness; needs real content/photos |
| Playful / friendly | Approachable | Consumer, education, onboarding | Undermines trust in regulated domains |
| Dark technical | Focused, modern | Dev tools, dashboards, monitoring | Contrast discipline; not "invert colors" |

Recommended combos: minimal functional + editorial; swiss + data-dense; dark technical + terminal; neubrutalism + playful; luxury + editorial.

## Anti-generic tells (P0/P1)

These are the strongest signals that a design was generated by default. Their presence is not automatically wrong — it requires a one-sentence justification addressed to *this* product:

- Purple-to-blue (or purple-pink, cyan-magenta) gradient anywhere, including gradient text.
- Hero = big number/headline + small label + gradient accent + three identical cards.
- Identical rounded cards for everything, one radius regardless of hierarchy, same soft shadow.
- Tracked-out ALL-CAPS eyebrow above every heading.
- Meta strings joined with middle dots (`A · B · C`) and `WORD — fragment` labels.
- Monospace face for small labels as a style signal, `→` appended to every link/button.
- Blue-purple "AI gradient" backgrounds, generic glassmorphism wallpaper, stock "AI look".
- Generic copy: "unlock the power", fake metrics, invented testimonials and logos.
- Decorative icons for every feature, motion on everything (fade+slide on each section, hover on every card).
- Numbered markers (01/02/03) on content that is not a sequence.
- Accenting one word of a headline with italic/bold/color as the only idea.

(Consolidated from Anthropic `frontend-design`, `anti-ai-slop` P0–P6 taxonomy and StyleKit; see `REFERENCE-PROTOCOL.md`.)

## Two tests before recommending a direction

1. **Purpose test** — can you write one honest sentence explaining why this technique serves *this* product?
2. **Convergence test** — does the same technique appear across unrelated screens for no reason?

## Effect and motion budget

- Max 1–2 high-impact effects per view (aurora, beams, tilt, particles, shaders).
- One animated background per view; one text effect per section.
- Animate transform/opacity; springs over linear; respect `prefers-reduced-motion`.
- Motion must answer a user action or explain a change; non-triggered motion only as one orchestrated moment.

## Output for the brief

For each proposed direction write: style name(s), why it fits the subject and philosophy, one composition idea, palette intent (not hex values yet), typography personality, motion intent, the anti-generic list to avoid, and the main risk.
