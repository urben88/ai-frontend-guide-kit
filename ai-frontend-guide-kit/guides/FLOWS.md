# Flows of the AI Frontend Guide kit

Generated by `node tools/flow.mjs list`; do not edit by hand. Every design conversation declares one route with `node tools/flow.mjs start <route>` and follows its steps in order: `node tools/flow.mjs done <step>` refuses a skipped step or a missing artifact. Skills marked "if installed" are optional; without them, use `guides/08-PHILOSOPHY.md`.

## Routes

| Route | When | Steps |
|---|---|---|
| `new` | New frontend or major build (phases 1 → 2 → 3) | intake → direction → ux → tokens → compose → polish |
| `direction` | Direction only, no UI | intake → direction |
| `ux` | UX only or UX redesign, no UI work | intake → ux |
| `iterate` | Small change or custom component | intake → iterate → polish |
| `polish` | Polish only or visual QA | intake → polish |
| `redesign` | Visual redesign of an existing screen | intake → redesign → polish |
| `visual-feedback` | Point-and-change in the browser (React) | intake → visual-feedback |
| `architecture` | Folder map, or FSD structure when asked | intake → architecture |
